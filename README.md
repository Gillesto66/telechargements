# Téléchargements

Les versions installables des applications de Gilles MEDENOU, présentées sur [son portfolio](https://gillesportefolio.vercel.app).

Ce dépôt ne contient **aucun code source** : seulement des [Releases](https://github.com/Gillesto66/telechargements/releases), une par application et par version. Chaque Release dit ce que la version fait, ce qui n'est pas encore prouvé, et donne les empreintes SHA-256 des fichiers.

Ces applications ne sont pas distribuées par le Play Store ni signées par un éditeur reconnu : Android et Windows demandent une autorisation à l'installation.
